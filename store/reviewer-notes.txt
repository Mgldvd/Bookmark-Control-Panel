First public listing of an existing unlisted add-on. Preserve GUID bookmark-dashboard@local-extension.
No build, transpilation, minification, third-party runtime libraries, or remote executable code. The submitted archive is the original human-readable JavaScript, HTML, CSS, SVG, and locale JSON. Run ./package.sh (POSIX shell + Python 3) to reproduce the ZIP; npm is only needed for development checks.
Firefox desktop >=142. Open a new tab, toolbar action, or Alt+Shift+B. New-tab replacement is explicitly disclosed. No account needed. Existing bookmarks are only read on startup; editing is user-initiated.
Privacy: no required data transmission; remote favicons default off and are gated on optional bookmarksInfo consent. Unsplash API calls and cached Unsplash backgrounds require authenticationInfo and searchTerms consent. Remote backgrounds are deferred until the current consent is loaded. Revocation removes remote favicons and Unsplash backgrounds. Custom remote background URLs are explicitly chosen by the user; uploaded files and gradients stay local. No telemetry or analytics. See attached listing privacy policy.

To test optional consent, toggle Show favicons in Settings > General, or select Unsplash in Settings > Background. Rejecting optional permissions keeps local organization available. Revocation can be tested in about:addons > Permissions and data.
